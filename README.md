

# CSRiemann

C++ frontend for Fortran Cube Sphere code.

# Steps to run

- Download and set up DGCALC (with all submodules)
- Download SPGEOMESH group with all submodules
- Compile the CubeSphere project, as a library
- This project should now run.

Some tests will run without first compiling CubeSphere.
